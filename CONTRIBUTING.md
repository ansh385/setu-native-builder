# Contributing to Setu

Thanks for contributing.

- Open an issue before major changes.
- Keep pull requests focused and describe the problem solved.
- Include tests for validation or configuration changes.
- Include responsive screenshots for significant UI changes.
- Never commit API keys, signing keys, certificates, tokens, or website credentials.
- Do not claim APK/IPA builds work unless they were actually built and tested with the target toolchain.

## Local checks

```bash
npm install
npm test
npm run build
```
